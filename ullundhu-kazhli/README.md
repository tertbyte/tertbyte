# URUL — Premium South Indian Pantry

A minimal, premium ecommerce concept for **Ullundhu Kazhji Mix** and **Roasted Salt**.

## Included
- Responsive luxury/minimal storefront
- Product cards and product-first visual system
- Working client-side cart
- Mobile navigation
- Brand/story/journal sections
- Checkout handoff placeholder
- No framework required

## Run
Open `index.html` locally or deploy the `ullundhu-kazhli` folder to Vercel, Netlify, GitHub Pages, or any static host.
